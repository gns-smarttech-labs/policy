Webhook API Integration Specification

Automated Contact Synchronization Protocol

When a webhook URL is configured, Business Card Scanner dispatches contact sync events to your custom endpoint using HTTP POST with Content-Type: application/json.

📡 Request Specification

HTTP Method: POST
Header: Content-Type: application/json
Body: JSON Array of Webhook Action Objects

JSON Payload Schema

Payload Request Body (JSON) 
[
  {
    "action": "NEW | UPDATE | DELETE",
    "id": "contact_id_string",
    "contact": {
      "id": "contact_id_string",
      "name": "John Doe",
      "company": "Acme Inc",
      "job_title": "Senior Engineer",
      "email": "john.doe@acme.com",
      "website": "https://acme.com",
      "address": "123 Business Way, Suite 100",
      "mobiles": [
        "+1234567890"
      ],
      "landlines": [],
      "groups": [
        "Work",
        "Clients"
      ],
      "custom_fields": {
        "LinkedIn": "https://linkedin.com/in/johndoe"
      }
    }
  }
]

📥 Response Expectation

Your endpoint or CRM middleware (e.g. Zapier, Make, HubSpot) should return an HTTP status code in the 200–299 range to indicate successful delivery.

Expected Response Body (JSON) 
{
  "status": "success",
  "message": "Processed 1 contact(s)"
}
